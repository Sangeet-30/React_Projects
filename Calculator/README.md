# React Calculator

A responsive calculator built with React to practice React fundamentals, component-based UI development, state management, and responsive CSS.

## 🚀 Live Demo

[Calculator Live Demo](https://sangeet-30.github.io/React_Projects/Calculator/)

## 📌 Overview

This Calculator is a React-based project designed to strengthen my understanding of React while building a practical and responsive application.

The calculator provides a simple interface for performing common arithmetic operations and is designed to work smoothly across desktop, tablet, and mobile screen sizes.

The project also focuses on creating a clean component structure and responsive layout without relying on excessive media queries.

## ✨ Features

- Perform basic arithmetic calculations
- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear calculator input
- Responsive calculator layout
- Responsive button sizing
- Responsive display
- Works across desktop, tablet, and mobile screens
- Clean and simple user interface
- GitHub Pages deployment
