# React Calculator

A responsive calculator built with React and CSS Modules.

## Features

- Basic arithmetic operations
- Operator precedence
- Decimal number support
- Backspace functionality
- Clear button
- Division-by-zero error handling
- Responsive layout
- Interactive button effects
- Custom calculator UI

## Technologies Used

- React
- JavaScript
- CSS
- CSS Modules
- Vite

## How to Run

```bash
npm install
npm run dev
